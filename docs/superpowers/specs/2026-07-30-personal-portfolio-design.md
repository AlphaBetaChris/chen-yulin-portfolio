# 陈昱霖综合个人主页设计

## 目标

为陈昱霖制作一份可长期维护的中英文综合个人主页。网站既能用于日常个人展示，也能服务研究生申请、科研交流与实习求职。首版以简历中的真实资料为唯一事实来源，并使用简历中的真实证件照、电话和邮箱。

## 视觉方向

采用已选定的“学术编辑风”：暖米白纸张底色、墨绿色正文、克制的灰绿色辅助色、衬线标题与无衬线正文。页面像一份精心排版的个人专刊，强调可信度、阅读节奏和内容层级，不采用通用科技渐变、霓虹效果或模板化卡片堆叠。

桌面端使用宽版杂志网格和编号栏目；移动端自动收为单列，保留标题节奏、分隔线和内容优先级。动效只用于页面初次进入与导航反馈，并尊重系统的“减少动态效果”设置。

## 页面结构

网站为单页结构：

1. 顶部导航：姓名标识、栏目锚点、中英文切换。
2. 首屏：真实姓名、双语定位、个人介绍、真实照片和主要行动入口。
3. 关键数据：专业前 15%、绩点 3.91/5.0、7 项荣誉、2 个国家级项目。
4. 关于我：计算机基础、数学建模、AI 兴趣与持续学习方向。
5. 教育背景：西南大学计算机科学与技术专业、核心课程、成绩与 CET-4。
6. 荣誉奖项：按时间展示奖学金、数学建模、蓝桥杯与创新创业奖项。
7. 项目经历：《寻迹土家》和《HUG》，分别展示项目目标、角色、职责和能力标签。
8. 专业技能：编程语言、数学建模、小程序开发、软件测试、AI 工具、Git、LaTeX 和 Linux。
9. 联系方式：真实电话和学校邮箱，提供可点击的拨号与邮件链接。
10. 页脚：版权信息、最后更新年份和返回顶部入口。

政治面貌、出生年月和籍贯作为“个人档案”中的次要信息展示，不在首屏强调。

## 双语策略

默认显示中文。语言切换由页面顶部的单一按钮控制，并满足以下规则：

- 切换后页面所有可见内容、导航和辅助标签同步变更。
- 选择保存在浏览器本地；再次访问时沿用上次选择。
- 首次访问且没有本地选择时，以中文为默认语言。
- 文档语言属性同步更新为 `zh-CN` 或 `en`，便于辅助技术和搜索引擎识别。
- 中英文内容分别人工撰写，不使用运行时机器翻译。

## 技术方案

使用 React、TypeScript 和 Vite 构建纯静态站点，不依赖后端、数据库或外部 API。页面内容集中保存在一个类型化数据模块中，展示组件只负责布局和交互。Vite 使用相对资源路径，使构建产物可以部署到任意 GitHub Pages 仓库子路径。

仓库命名为 `chen-yulin-portfolio`，初始为私有仓库。制作阶段不启用 GitHub Pages；网站经陈昱霖确认后再公开仓库或启用 Pages，避免未完成页面提前公开。

## 交互与无障碍

- 顶部导航使用语义化导航和锚点。
- 当前语言切换按钮具有明确的可访问名称。
- 邮箱和电话使用原生 `mailto:` 与 `tel:` 链接。
- 键盘焦点有清晰可见样式。
- 图片包含双语替代文本，装饰元素不干扰读屏。
- 色彩对比满足正文可读性，正文不依赖颜色传达关键信息。
- 移动端触控目标不小于 44 像素。

## 异常与降级

- 本地语言偏好读取失败时回退为中文，不影响页面渲染。
- JavaScript 正常加载时提供语言切换；构建失败则不发布。
- 外部链接仅使用电话和邮箱，不引入未经确认的 GitHub、LinkedIn 或项目演示地址。
- 字体加载失败时使用系统衬线与无衬线字体回退。

## 测试与验收

- 自动化测试验证默认中文、语言切换、偏好持久化、文档语言属性、主要栏目和真实联系方式。
- TypeScript 类型检查必须通过。
- 生产构建必须成功。
- 验证构建产物使用相对资源路径，适配 GitHub Pages 子路径。
- 检查桌面与移动端布局、键盘焦点、减少动态效果和联系方式可点击性。

## 首版范围外

首版不包含博客、后台管理、留言表单、访问统计、项目独立详情页和未经确认的社交账号链接。这些可在后续内容积累后添加。
